# Modern single-role image archive closure

This opt-in diagnostic joins strict OCI/Docker content verification and the
existing pinned Moby 28.0.4 ancillary byte checker. It does not enable archive
acceptance, packaging, upload, import, transfer, deployment, or any provider write.
The normal workflow and existing legacy validator are unchanged. Combined saves
remain refused; only the independently sampled single expected image is checked.

The verifier holds one no-follow regular-file descriptor throughout. It checks:
- bounded physical USTAR header scan before tarfile decoding: regular/dir records
  only, checked octal sizes/checksums, zero padding and bounded two-marker ending;
- canonical paths, no links/GNU/PAX/extensions/sparse/duplicates/unknown members;
- one OCI manifest and one Docker row, tagless, exact linux/amd64 config digest;
- exact OCI descriptor fields/media/size/hash and ordered Docker layer references;
- bounded uncompressed layers whose bytes match digest and config DiffID;
- exact LayerSources descriptors, with no unrelated or missing entries;
- precisely one ancillary node per layer, each content-addressed and bounded;
- all ancillary raw bytes, exact config, and exporter metadata consumed by the
  trusted locally built Go helper, not an archive program or supplied boolean;
- unchanged descriptor identity/size/timestamps at the end of verification.

The Go helper requires the measured exporter source version/API/commit/platform/
storage tuple. Unsupported healthcheck fields, different layouts/media/platforms,
or missing proof fail closed. An observed successful ancillary-only check is not
reused as a substitute for this complete archive check. Full closure still needs
its own exact hosted qualification; unit tests do not establish that outcome.

The opted-in sampler records a closed `modern_closure` summary (or unavailable),
and deletes the archive as before. `archive_accepted` and `deployment_authorized`
remain false. No binary/path/config/auxiliary contents appear in its output.

## Offline synthetic test

Build only the stdlib proof command into a temporary directory, then set
`GARM_TEST_ANCILLARY_PROOF` to it and run `test_modern_single_role_archive.py`.
That test invokes the actual helper; it never mocks successful derivation.
Without that variable, these four integration tests explicitly skip. Ordinary
closure-negative tests in `test_verify_single_role_archive.py` need only Python.
The committed fixture contains entirely synthetic config and auxiliary bytes,
generated by the pinned Go DeriveV28 routine, with UTC and one fixed synthetic
layer; there are no actual image configs or credentials in the fixture.
